## Unit 1 — Back to School

| Book activity | Skill / "I can" | App |
|---|---|---|
| Act. 1 (p11) match subject words to pictures | Use a glossary; use topic words when I speak | Learn the words, Word practice |
| Act. 2 (p12) easy / difficult / interesting / boring | Ask and answer questions about what I heard | Vocabulary (describing words); Grammar: *Asking questions* |
| Act. 3a (p13) read "My Favourite Subject" | Slow down, pause at commas, use context clues | Reading: *The First Day Back* (original); Grammar: *because*, *like / likes* |
| Act. 3b (p14) answer questions | Literal questions; find a detail to support an answer | Reading questions |

**Vocabulary:** subject, science, social studies, Islamic studies, CCDI, maths, English, art,
favourite, easy, difficult, interesting, boring, classroom, teacher, learn.
**Game:** Sort It — which subject (science / social studies / CCDI)?

## Unit 2 — Daily Routines

| Book activity | Skill / "I can" | App |
|---|---|---|
| Act. 1 (p16) match routine phrases to pictures | Use a glossary; spot topic words | Learn the words (phrases), Word practice |
| Act. 2a–c (pp17–19) read "Ahmed's School Day"; questions | Procedural text features; literal and inferential questions | Reading: *Saif's Busy Day* (original); Grammar: *First, then, after* |
| Act. 3 (p20) answer with always / sometimes / never | Subject + matching verb; full sentences | Grammar: *He wakes up / I wake up*, *always, sometimes, never* |

**Vocabulary:** wake up, take a shower, get dressed, brush teeth, eat breakfast, go to school,
do homework, go to bed, play football, bus, routine, always, sometimes, never, morning, evening.
**Game:** Sort It — morning or evening?

## Unit 3 — Kind Hearts, Kind Words

| Book activity | Skill / "I can" | App |
|---|---|---|
| Act. 1 (p22) match sentences to words and pictures | Use a glossary; ask a question about something heard | Learn the words, Sentences |
| Act. 2a–c (pp23–25) read "The Kind Girl"; questions | Literal questions; connect to own experience | Reading: *The New Girl* (original) |
| Act. 3 (p26) complete with he / him / her / she | Write a sentence using new vocabulary; inferential questions | Grammar: *he, him, she, her* |

**Vocabulary:** kind, helpful, happy, sad, friendly, smile, laugh, talk, share, help, sorry,
mistake, friend, gift, playground, thank you.
**Game:** Sort It — kind or unkind?

## Unit 4 — What We Wear

| Book activity | Skill / "I can" | App |
|---|---|---|
| Act. 1 (p29) match word to picture; complete sentences | Say a sentence that uses a new vocabulary word correctly | Learn the words, Word practice (picture / listen / meaning / fill-in) |
| Act. 2 (p30) find and describe items — "This is / These are" | Use adjectives to add detail | Grammar: *This is / These are*, *Describing words* |
| Act. 3 (p31) read "Clothing in the UAE"; choose answers | Write a sentence using new vocabulary; cultural awareness | Sentences; Reading: *Mariam's Two Trips* (original text, same theme & skills) |

jacket, trousers, warm, cool, light, colourful, comfortable.
**Game:** Sort It — hot summer / cold winter clothes.

## Unit 5 — My Body, My Health

| Book activity | Skill / "I can" | App |
|---|---|---|
| Act. 1 (p34) do the sentences match the pictures? | Read high-frequency words; use a glossary | Learn the words, Word practice, Sentences |
| Act. 2 (p35) write a sentence for each picture | Break multi-syllable words into syllables | Grammar: *ache words & syllables* |
| Act. 3a–c (pp36–38) "Hessa Feels Sick" story + questions | Spot contractions (do not → don't); literal questions | Grammar: *Short forms*, *Asking about health*; Reading: *Rashid Has a Toothache* (original) |
| Act. 4 (p39) draw and write 3 sentences (word bank) | Apostrophes; phonics pattern for spelling | Spelling (missing letters, unscramble, dictation) |

**Vocabulary:** head, shoulder, back, stomach, teeth, ears, eyes, arm, headache, toothache,
stomachache, backache, hurt, pain, sick, better, doctor, hospital, healthy.
**Game:** Sort It — healthy / not healthy.
