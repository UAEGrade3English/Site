## Unit 4 — What We Wear

| Book activity | Skill / "I can" | App |
|---|---|---|
| Act. 1 (p29) match word to picture; complete sentences | Say a sentence that uses a new vocabulary word correctly | Learn the words, Word practice (picture / listen / meaning / fill-in) |
| Act. 2 (p30) find and describe items — "This is / These are" | Use adjectives to add detail | Grammar: *This is / These are*, *Describing words* |
| Act. 3 (p31) read "Clothing in the UAE"; choose answers | Write a sentence using new vocabulary; cultural awareness | Sentences; Reading: *Mariam's Two Trips* (original text, same theme & skills) |
| Act. 4 (p32) speech bubbles with quotation marks | Write letters the same size and shape; quotation marks | Grammar: *Speech marks* |

**Vocabulary:** shoes, shirt, T-shirt, dress, socks, hat, bag, boots, trainers, jeans, kandura,
jacket, trousers, warm, cool, light, colourful, comfortable.
**Game:** Sort It — hot summer / cold winter clothes.

## Unit 5 — My Body, My Health

| Book activity | Skill / "I can" | App |
|---|---|---|
| Act. 1 (p34) do the sentences match the pictures? | Read high-frequency words; use a glossary | Learn the words, Word practice, Sentences |
| Act. 2 (p35) write a sentence for each picture | Break multi-syllable words into syllables | Grammar: *ache words & syllables* |
| Act. 3a–c (pp36–38) "Hessa Feels Sick" story + questions | Spot contractions (do not → don't); literal questions | Grammar: *Short forms*, *Asking about health*; Reading: *Rashid Has a Toothache* (original) |
| Act. 4 (p39) draw and write 3 sentences (word bank) | Apostrophes; phonics pattern for spelling | Spelling (missing letters, unscramble, dictation) |

**Vocabulary:** head, shoulder, back, stomach, teeth, ears, eyes, arm, headache, toothache,
stomachache, backache, hurt, pain, sick, better, doctor, hospital, healthy.
**Game:** Sort It — healthy / not healthy.
